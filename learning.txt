Creating and Managing Users
1. Create new user (basic): 
	useradd username
2. Create user (interactive, Debian/Ubuntu)
	adduser username
3. set or change password
	passwd username
4. Add user to group
	usermod -aG groupname username {a- append, G- group>}
5. Delete user
	userdel username { not remove directory}
6. Delete user and home directory
	userdel -r username


	
Managing Groups

1. Create a new group on the system.
	groupadd groupname
2. Delete an existing grooup.
	groupdel groupaneme
3. Add a user to an existing group.
	gpasswd -a username groupename
4. Remove a user from a group
	gpasswd -d username groupname
5. Display all groups a user belongs to.
	groups username
6. Show user id , groups ids 
	id username

Understanding Sudo access.

1.sudo= "superusser do" , run command as root.
2 Run single command with root privieges
	sudo command
3. Start root shell (interactive)
	sudo -i
4 Run as different user
	sudo -u username command
	
5 configuration file : /etc/sudoers

Cofniguring sudo permissions
1. visudo - safe way to edit /etc/sudoers
2. Allow user sudo
	username ALL= (ALL:ALL) ALL
3. Allow without password
	userame ALL=(ALL) NOPASSWD: ALL
4. Speific commands only
	username ALL=/usr/bin/sysemctl restart nginx
5. Group-based Sudo 
	%groupname ALL=(ALL:ALL) ALL
6. Drop-in config files (cleaner)
	/etc/sudoers.d

	
Practical User Management Scenarios
1. Onboarding developers
	adduser, add to groups (sudo , docker, developers)
2. Service account 
	useradd -r-s /bin/false (no login,for apps)
3. Temporary contractor
	create user , set expiration with change -E
4. Shared team directory
	create group, set group ownership , use 2775
5. Offboading 
	Lock account (usermod -L),backup data , delete
6. Audit sudoers
	check sudo /etc/sudoers.d

Creataing LVM


1. Check disks
	lsblk
2. Create Physical Volume
	pvcrete /dev/sda dev/sdb /dev/sdc
3. Create Volume Group
	lvcreate lvname /dev/sda /dev/sdb /dev/sdc
4. Create Logical Volume
	# Use all remaining free space (extents)
	lvcreate -l 100%FREE -n lvname vgname
	or
	# Use a specific size in Gigabytes
	lvcreate -L 10G -n lvname vgname   
5. format lvm 
	mkfs.xfs /dev/vgname/lvname
6. Mount lvm
	mkdir -p /dirname
	mount /dev/vgname/lvname /dirname
8. Get UUID for mount point
    blkid
7. make mount presist
	vi /etc/fstab
	add : 
	UUID=3585fce7-c337-4482-bda0-86b325a09f44 /projects    xfs  defaults 0 0
8. verify : 
	mount -a
	or 
	mount | grep direname
