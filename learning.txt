Creating and Managing Users
1. Create new user (basic):
	useradd username
2. Create user (interactive, Debian/Ubuntu)
	adduser username
3. set or change password
	passwd username
4. Add user to group
	usermod -aG groupname username {a- append, G- group>}
5. Delete user
	userdel username { not remove directory}
6. Delete user and home directory
	userdel -r username



Managing Groups

1. Create a new group on the system.
	groupadd groupname
2. Delete an existing grooup.
	groupdel groupaneme
3. Add a user to an existing group.
	gpasswd -a username groupename
4. Remove a user from a group
	gpasswd -d username groupname
5. Display all groups a user belongs to.
	groups username
6. Show user id , groups ids
	id username

Creataing LVM


1. Check disks
	lsblk
2. Create Physical Volume
	pvcrete /dev/sda dev/sdb /dev/sdc
3. Create Volume Group
	lvcreate lvname /dev/sda /dev/sdb /dev/sdc
4. Create Logical Volume
	# Use all remaining free space (extents)
	lvcreate -l 100%FREE -n lvname vgname
	or
	# Use a specific size in Gigabytes
	lvcreate -L 10G -n lvname vgname
5. format lvm
	mkfs.xfs /dev/vgname/lvname
6. Mount lvm
	mkdir -p /dirname
	mount /dev/vgname/lvname /dirname
8. Get UUID for mount point
    blkid
7. make mount presist
	vi /etc/fstab
	add :
	UUID=3585fce7-c337-4482-bda0-86b325a09f44 /projects    xfs  defaults 0 0
8. verify :
	mount -a
	or
	mount | grep direname

SELinux

	sestatus
	Results : Enforcing | Permissive | Disabled
2. Show lebels
	ls -Z  {view lables}
	ls -Zd /path {view direcotry lables}
3. Restore default labels
	restorecon
4. syntex : system_u:system_r:httpd_t:s0
5. Temporary / direct label change
	chcon
6. Persistent SELinux policy mapping
	semanage fcontext
	restorecon
7. Change seliux policy
	chcon -t httpd_sys_content_t /web/index.html  {Temporary}
8. restorecon
	restorecon -Rv /web
9. semanage {make paramanet changes}
	semanage fcontext -a -t httpd_sys_content_t "/web(/.*)?"
10. verfiy : restorecon -Rv /web

11. SELinux Boolean (SELinux feature switches.)
	view all booleans
		getsebool -a
	enable permanent on (-P)
		setsebool -P httpd_can_network_connect on

ACL (Access Control List) for permission on linux +
1.  Give Bob Read Access Using ACL
    setfacl -m u:bob:r /secret.txt
        setfacl - set an ACL
        -m      - Modify an ACL
        u:bob:r - User Bob gets Read permission
2.  Verify
    getfacl /secret.txt
3. Mask
    setfacl -m m:r-- /secret.txt  { max permission on file by acl}
4. Remove a acl
    setfacl -x u:bob /secret.txt
5. Remove all ACls
    setfacl -b file
6. Default ACL
    setfacl -d -m g:developers:rwx /project
        -d    This is the important part.
        It means:
        Default ACL
        Not for the directory itself.
        For future files and directories created inside it.
